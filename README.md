# TimeManager

TimeManager 是一个仍在开发中的 Flutter 学习时间与计划管理 App。

目前支持：

- 自由新增、编辑和删除学习计划
- 配置多套独立学习方案，复制后调整任务、时长和后台暂停设置
- 在日历中设置每周安排，并为指定日期、多个日期或连续假期批量分配方案或休息日
- 计划卡片适配窄屏与大字体；编辑时提供未保存确认、保存反馈和失败重试
- 批量选择和删除学习计划
- 首页和管理页支持按名称搜索、按今日状态筛选；批量管理明确显示全部计划
- 每个计划可独立设置进入后台时是否自动暂停
- 自定义首页激励文案，通过醒目的学习按钮开始或继续计划
- 首页提供快捷新增入口与今日学习总览，设置页使用独立铃声选择和试听面板
- 首页可一键开始或继续学习，优先显示正在运行的计划；计划卡片按需加载，切换页面或返回首页时保留列表位置
- 按计划进行学习倒计时，并可暂停或调整本次剩余时间
- 保存剩余时间和已学习进度，下次进入时继续
- 查看今日学习统计与各计划完成率
- 查看近 7 天每日实际学习时长、累计时长、学习天数、日均时长和最高学习日，保留已删除计划的历史记录
- 从统计页进入学习复盘，查看学习月历、当前与最长连续学习天数、日期范围统计及当日计划明细
- 使用本地存储保留计划、进度、学习记录和设置
- 导出包含计划、学习历史、设置、图片和铃声的完整备份；覆盖恢复前保留上一次数据副本
- 本地数据加载失败时提供重试与备份恢复；保存失败时保留内存修改，并提供无需再次编辑的重试入口
- 支持简体中文和 English 界面切换，并保存语言偏好
- 倒计时结束可选择铃声、震动或无提醒，提供五种可试听的提示音
- 可从本机选择计划图片，裁剪后保存到本地；首页、计划管理和统计页使用统一的方形图片区展示图标
- 可从本机选择提示音、截取片段，用作倒计时提醒
- 后台继续计时的计划使用 Android 系统调度完成通知

## 日常学习流程

底部导航提供“首页、日历、统计、设置”。首页只展示今日方案的任务，点击“切换今日方案”可临时改用另一套或休息日；切换会结算并暂停原方案的计时、取消关联提醒，保留各方案当天的进度。切回原方案后可继续学习。今日累计时长包含所有已学任务，完成度和剩余时间对应当前方案。

## 日历与学习方案

在首页右上角点击“管理计划”进入方案列表，新建、重命名、复制或删除方案，并通过每套方案的“编辑任务”独立管理任务。复制会创建新的任务，只复制配置；修改某套方案会同步今天和未来使用它的日期，今天已学时长保留，并按新目标调整剩余时间。删除方案时选择替代方案或休息日，排期引用会统一替换，学习历史保留；至少保留一套方案。

“每周安排”可分别配置周一至周日，也可批量设置周一至周五、周末。日历点击日期只预览任务和学习记录；点击顶部“批量管理”即可多选日期，支持跨月选择不连续日期，也可通过“选择日期区间”一次安排连续假期。底部操作条固定显示选中数量、分配方案和恢复每周安排，选择一个日期时同样适用。单独分配的日期优先于每周规则，点击“恢复每周安排”可移除覆盖。方案与任务统一从首页管理入口编辑，节假日和调休日由用户手动安排。

休息日没有学习任务，当天已学记录继续保留。过去日期只展示实际学习记录，不能重新排期；方案与任务名称会随新学习记录保存，后续删除方案仍可查看其记录。日期归属遵循设置中的每日重置时间。窄屏和大字号使用日期列表，保持日期和方案名称可读。

升级后，原有任务、进度、图片和历史会迁移到“默认方案”，初始每周七天都使用它，可按自己的作息继续调整。

## 计时与保存

首页点击“开始学习”或“继续学习”后，直接开始或恢复倒计时。打开正在运行的计划会保留原会话；已完成的计划只展示结果。计时页底部固定显示开始、继续或暂停按钮，以及调整时间入口，正文滚动时仍可操作；完成后可直接返回首页。

调整时间时先暂停计时，编辑期间不计入学习时长。“+1／+5／+15 分钟”只修改输入，保存后才更新剩余时间。原本运行中的计划在保存或取消后恢复，原本暂停的计划保持暂停。切到后台时等待回到前台再恢复；计划已删除、已完成或学习日期变化时，不恢复旧会话。输入无效或增量超出范围时，快捷增量不可用，保存期间不能重复提交、编辑或关闭面板。

退出计时页时会暂停并保存。保存失败可以选择留在计时页，或保留内存修改返回首页；留在页面时保持暂停。首页和计时页提供持续的未保存提示及重试入口，无需重新编辑即可保存。尚未写入本地的修改可能在应用关闭后丢失，也可以通过完整备份导出当前内存数据。

## 学习复盘

从统计页点击“学习复盘”，可以查看月历、连续学习天数及指定日期范围内的实际学习记录。窄屏或大字号下，月历会自动改为可点击的日期列表；点击日期可查看当日各计划的学习时长。已删除计划的记录仍会保留，并合并展示。

当天实际学习超过 0 秒即算一个学习日，日期边界遵循设置中的每日重置时间。今天尚未学习时，当前连续值暂时保留截至昨天的连续天数；历史最长连续值按全部有效记录计算。

范围统计支持近 7 天、近 30 天、本月和自定义日期，两端日期均计入。日均时长包含没有记录的日子；最高学习日并列时显示最近一天。

范围统计还可对比紧邻其前、天数相同的上一周期，查看实际学习时长的增减。上一周期没有学习时长时，不计算百分比变化。计划时间分布按时长降序展示各计划及占比，可打开完整列表；“只看学习日”会隐藏零时长日期，并保留原有统计口径。

## 数据备份与恢复

在设置页的“数据管理”中选择“导出备份”“从备份恢复”或“恢复上次替换前的数据”。独立备份页面会展示进度、结果和恢复预览。备份是单个 UTF-8 JSON 文件，默认文件名包含日期与时间，格式版本为 2；文件包含创建时间、应用版本、所有方案、星期规则、日期覆盖、计划与设置快照，以及按引用去重的 Base64 图片和铃声。仍可导入原有格式版本 1 的备份，并迁移为默认方案。

导出包含当前内存中的修改，即使最近一次保存失败也可导出。所有正在运行的计划按同一时间点计算进度，在备份中保存为暂停状态；本机计时继续。只读取应用管理目录中的媒体；图片或铃声缺失、不可读取时，会列出受影响的项目，由你选择取消或继续。继续后保留计划和历史，恢复时使用对应内置图标或铃声。

恢复前会检查文件大小、格式、版本、数据与媒体，并展示备份时间、计划数、记录数、有效历史范围及媒体情况。文件上限为 **64 MiB**。选择器取消或预览取消均不改变当前数据；确认恢复会替换当前计划、历史、设置和媒体。导入媒体会获得新的应用本地路径，不采用文件中提供的路径。

替换前先尝试保存未写入的修改；保存失败会停止恢复，此时仍可导出内存数据。恢复使用事务日志，全部写入成功后才更新界面；失败会回滚，进程中断后会在下次启动先处理事务。回滚暂时失败时保留日志与文件，并提供重试入口。恢复后的计划全部暂停，保留备份中的进度；跨学习日的今日进度按恢复后的每日重置设置处理，历史日期保持原有归属。

仅保留最近一次成功替换前的副本，下一次成功恢复后才轮换。该副本保存在本机，不能代替导出的备份；卸载应用或“清空全部数据”会删除它。原始快照损坏时会保留其原始内容，不将其转换为空计划；该原始副本无法用于正常恢复时会明确提示。

启动加载失败不会以默认值覆盖原数据，可选择重试或从备份恢复。首页与设置页会持续显示未保存提示，重试成功后移除；连续修改始终保存最新内容。计划快照使用版本 6，设置快照继续使用版本 4，兼容原有计划快照版本 1 至 5，并保留旧存储键中的原始数据。

备份中包含你的学习数据和媒体，请自行选择合适的保存位置。

## 本地验证与界面预览

```sh
flutter gen-l10n
flutter analyze
flutter test
```

备份测试覆盖完整往返、缺失媒体、保存重试、损坏数据保护，以及各恢复阶段失败与进程中断。学习流程测试覆盖一键开始、调整后的状态恢复、后台与跨日保护、保存失败返回及大量计划按需加载。界面测试覆盖 320／390dp、中英文、浅深色与 1.0／1.5 倍字体，包含计时页、调整面板、键盘遮挡及未保存确认。沿用 Widget 截图机制，设置 `TIMEMANAGER_UI_PREVIEW=1` 后运行 `test/ui_polish_test.dart`，预览输出到已忽略的 `build/ui-previews`。

## 下载

Android APK 通过 GitHub Releases 提供：[下载最新版 Release](https://github.com/iLLyaaaaaa/timemanager/releases/latest)。

请按手机或设备的 CPU 架构选择安装包：

- `arm64-v8a`：大多数现代 Android 手机，建议优先选择。
- `armeabi-v7a`：较旧的 32 位 ARM 设备。
- `x86_64`：部分 Android 模拟器和 x86-64 设备。

不确定设备架构时，可先尝试 `arm64-v8a`。如果系统提示安装包不兼容，再确认设备架构并下载对应版本。

## 本地运行

安装 Flutter 与 Android 开发环境后，在项目目录执行：

```sh
flutter pub get
flutter run
```

生成 Android APK：

```sh
flutter build apk --release --split-per-abi
```

本项目尚在开发中。构建产物和 APK 不纳入 Git 仓库。
